# Wedding Hashtag Maker

💍 Free wedding hashtag generator — turn your names into clever, punny, romantic, and classic hashtags in seconds.

## Features
- Name-based pun generation (128 last-name pun rules)
- 4 styles: Punny & Witty / Romantic / Short & Classic / Cute
- 10 vibe themes: Beach, Coffee, Cat, Dog, Wine, Sports, Travel, Books, Music, Food
- One-click copy & share
- Neon sign preview
- Email capture (bonus hashtags + free checklist)
- SEO: structured data, OG tags, FAQ schema, content skeleton

## Tech
- Pure static HTML/CSS/JS — no build step, deploy anywhere
- Wordbank embedded in page (51KB total)

## Deploy
Hosted on Vercel via GitHub. Domain: https://weddinghashtagmaker.com
